## Run 1: app not hidden (scenario `dopamine_roothide`)

| App | Result |
|---|---|
| JB Check | **Jailbroken**. Conclusive: known injection library loaded, `.jbroot-…/usr/lib/roothideinit.dylib` (200). Indicators: syscall stub does not trap, `csops: no svc #0x80 in first 8 insns` (304); package-manager URL scheme `sileo://` (905). |
| Integrity Check | Device **Elevated 56**; this app's runtime **Compromised 97**; protected verdict compromised. |

**Verdict: PASS for JB Check. Inconsistent for the full app**: the conclusive injector is scored in the
runtime domain, so the device domain only saw the URL scheme. Fixed in 1.3.0: both apps now use one rule
(`JailbreakEvidence`), and conclusive evidence in any domain makes the device **Compromised**.

**RootHide note:** RootHide hides the jailbreak by randomising the jailbreak root and removing `/var/jb`,
so every path-based check missed it. It was defeated here only because RootHide still injects
`roothideinit.dylib` into apps that are not on its Blacklist, and the dyld image list exposed it.

## Run 2: app hidden with RootHide's Blacklist (scenario `dopamine_roothide_hidden`)

| App | Result |
|---|---|
| JB Check | **Not jailbroken**. Conclusive: none. Indicators: none. All checks ran (filesystem, sandbox, images, hooks, environment, codesign, canary, urlSchemes), 36 ms. |
| Integrity Check | Device **Trusted 0**, runtime **Trusted 0**, inline guard clean, protected verdict trusted. |

**Verdict: FAIL (detection gap).** Blacklisting stops injection into the app and hides the package managers'
URL schemes, so the app sees a near-stock environment. Every signal from run 1 disappeared, including the
syscall-stub indicator, which shows that indicator came from the injected code and was a true positive.

## What 1.3.0 adds for this case (to be re-tested)

| Code | Check | Why it may survive per-app hiding |
|---|---|---|
| 110 `dyldModified` | Compares dyld's `__text` in memory with `/usr/lib/dyld` on disk (same LC_UUID) and checks the path dyld was loaded from | A jailbreak that patches or replaces dyld does so for every spawned process, hidden or not |
| 111 `userspaceReboot` | Reads `kern.userspacereboottime` | Dopamine restarts userspace after the exploit; this is kernel state, not in the app |
| 908 `previouslyJailbroken` | Keychain marker written when conclusive evidence was seen | The marker from run 1 survives hiding; reported as an indicator |
| server history | Reference server remembers the Secure Enclave / App Attest key that once sent conclusive evidence | A hidden re-run signed by the same key is raised to `high` and denied |
